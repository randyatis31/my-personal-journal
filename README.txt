MY PERSONAL JOURNAL - OFFLINE PWA

Publish the contents of this folder (not the zip itself) to an HTTPS static host such as GitHub Pages. Open the published address in Safari on iPhone, choose Share > Add to Home Screen > Add. Visit the site once online before testing offline.

Entries are stored only in local browser storage on each device. There is no login, encryption, or synchronization. The hosting site serves public application code but no journal entries. Export backups frequently and protect them. Avoid classified or sensitive operational content. Clearing Safari website data or deleting the app may delete entries.
